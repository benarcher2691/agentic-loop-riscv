# Tasks

Ordered. The loop agent takes the **first unchecked** task each iteration. Every task ends with
`make check` green (all benches PASS, synth without latches, fits the hx1k at 12 MHz) and a commit.
Architecture target, so no task requires rewriting an earlier one: `SOC` (clock, reset, IO) →
`Processor` (CPU) + `Memory` (RAM/ROM), plus small pure modules `Decoder`, `ALU`, `Clockworks`.

- [x] **Blinker.** `rtl/clockworks.v`: `Clockworks #(parameter SLOW = 0)(input CLK, output clk, output resetn)` — `clk` is `CLK` divided by 2^SLOW (SLOW = 0 passes CLK through); `resetn` is a power-on reset: low for the first 16 `CLK` cycles after power-up, then high forever (no reset button on the board). `rtl/soc.v`: `SOC #(parameter SLOW = 19)` instantiates `Clockworks`, and a 5-bit counter driven by `clk` and cleared by `!resetn` drives `LEDS`. Benches: `tb/clockworks_tb.v` (SLOW = 0 → clk follows CLK; SLOW = 3 → exactly one `clk` edge per 8 `CLK` edges over 64 cycles; `resetn` timing) and `tb/soc_tb.v` with `SOC #(.SLOW(0))`: LEDS = 0 during reset, then increments by exactly 1 per clock, wraps 31 → 0.

- [x] **LED patterns from ROM.** `rtl/memory.v`: `Memory(input clk, input [31:0] mem_addr, output reg [31:0] mem_rdata, input mem_rstrb)` — `reg [31:0] MEM [0:255]` (1 KB), synchronous read of `MEM[mem_addr[9:2]]` when `mem_rstrb` is high, initialised in an `initial` block. `SOC` gets `reg [31:0] PC` (starts at 0, advances by 4 each `clk`, wraps after the last initialised word) and shows `mem_rdata[4:0]` on LEDS. Bench: `tb/memory_tb.v` (read strobe, word addressing, rdata holds when strobe low) and `tb/soc_tb.v` checks LEDS follow the ROM word by word for two full passes against the same constants the ROM was initialised with.

- [ ] **Instruction decoder.** `rtl/decoder.v`: purely combinational `Decoder(input [31:0] instr, …)` with outputs `isALUreg, isALUimm, isBranch, isJALR, isJAL, isAUIPC, isLUI, isLoad, isStore, isSYSTEM` (one-hot over the 10 RV32I opcode classes), `rs1Id, rs2Id, rdId` (5 bits), `funct3` (3), `funct7` (7), and sign-extended 32-bit immediates `Iimm, Simm, Bimm, Uimm, Jimm` exactly as the RISC-V spec defines them (B and J have bit 0 = 0). Bench `tb/decoder_tb.v`: at least 15 hand-encoded instructions covering every class and every immediate format, including negative immediates (`addi x1,x0,-1` = `32'hFFF00093`), a backward `jal`, a backward `bne`, `sw` with negative offset, `lui` with bit 31 set; check **every** output for each. Also cross-check: encodings produced by the `RType/IType/...` functions in `lib/riscv_assembly.v` decode back to their fields.

- [ ] **ALU.** `rtl/alu.v`: combinational `ALU(input [31:0] in1, in2, input [2:0] funct3, input funct7_5, output [31:0] out, output EQ, LT, LTU)` implementing ADD/SUB (SUB when `funct7_5`, funct3 = 0), SLL, SLT, SLTU, XOR, SRL/SRA (SRA when `funct7_5`), OR, AND with the shift amount from `in2[4:0]`; `EQ`, `LT` (signed), `LTU` compare `in1` vs `in2` for later use by branches. Bench `tb/alu_tb.v`: for every operation, edge values (0, 1, −1, `0x7FFFFFFF`, `0x80000000`, shift by 0/1/31) plus ≥ 200 pseudo-random vectors (`$random` with a fixed seed), each checked against a behavioural reference in the bench using Verilog operators and `$signed`.

- [ ] **Processor: register-register and register-immediate instructions.** `rtl/processor.v`: `Processor(input clk, resetn, output [31:0] mem_addr, input [31:0] mem_rdata, output mem_rstrb)`. 32-entry `RegisterBank` with `x0` always 0; 3-state machine `FETCH_INSTR → FETCH_REGS → EXECUTE` (fetch the instruction from memory, then read rs1/rs2, then execute); uses `Decoder` and `ALU`; writes `rd` for `isALUreg` (rs2) and `isALUimm` (Iimm); `PC <= PC + 4`; `isSYSTEM` (EBREAK) halts: the state machine stops advancing PC. `SOC` now runs the `Processor` at full `CLK` speed on `Memory` (drop the LED counter; `Processor` gets a debug port `output [31:0] x1` = `RegisterBank[1]`, and `SOC` shows `x1[4:0]` on LEDS). Bench `tb/processor_tb.v` with its own memory model programmed through `lib/riscv_assembly.v`: covers every ALU-reg and ALU-imm instruction at least once, `x0` unchanged after `ADDI x0,x0,5`, a negative immediate, SRAI of a negative number; waits for halt (watch `dut.state`), then checks registers by hierarchical reference. `tb/soc_tb.v` keeps passing (a small program in `Memory`'s `initial` block).

- [ ] **Jumps: JAL and JALR.** `rd <= PC + 4`; JAL: `PC <= PC + Jimm`; JALR: `PC <= (rs1 + Iimm) & ~1`. Bench: forward and backward JAL, JALR through a register, `rd = x0` (no link written), a two-iteration loop counted in a register, link register value checked against the hand-computed address.

- [ ] **Branches.** BEQ, BNE, BLT, BGE, BLTU, BGEU using the ALU's `EQ/LT/LTU`; `PC <= PC + Bimm` when taken. Bench: each branch taken *and* not taken; signed vs unsigned distinguished with `−1` vs `0xFFFFFFFF` operands; a countdown loop that sums 1..10 into a register (expect 55).

- [ ] **LUI and AUIPC.** `LUI: rd <= Uimm`; `AUIPC: rd <= PC + Uimm`. Bench: LUI with bit 31 set, LUI + ADDI building a full 32-bit constant, AUIPC at two different PCs checked against hand-computed values.

- [ ] **Program suite.** `tb/programs_tb.v`: complete programs with hand-verifiable results — fibonacci(10) = 55 by loop; gcd(48, 18) = 6 by subtraction loop; a subroutine using `CALL`/`RET` (ra/x1) called twice with different arguments in `a0`; nested calls that save/restore ra via `ADDI sp` + (for now) registers, since loads/stores do not exist yet. Each program ends with EBREAK; results checked in registers. No RTL change expected unless a bug surfaces — if so, fix it and add a regression check.

- [ ] **Loads.** `Memory` and `Processor` become byte-addressable: LW, LH, LB, LHU, LBU with correct byte/halfword selection from `mem_addr[1:0]` and sign/zero extension; add a `LOAD` wait state for the synchronous memory. Bench: a data area written with `DATAW`/`DATAB` from the assembler; every load type at every byte offset (0..3 / 0,2) including values with the sign bit set; misaligned halfword at offset 1 is not required.

- [ ] **Stores.** `Memory` gets `input [31:0] mem_wdata, input [3:0] mem_wmask` (byte enables); SW, SH, SB write only the addressed bytes. Bench: store then load back for each width and offset; a byte store must not change the other three bytes (check `dut.MEM[i]` / the memory model directly); SW over a previous SB.

- [ ] **Memory-mapped IO.** In `SOC`: address bit 22 selects IO space instead of RAM. Word offsets (bit 2 → LEDS write, bit 3 → UART data write, bit 4 → UART status read: bit 9 = busy, using `corescore_emitter_uart` from `rtl/emitter_uart.v` at 12 MHz / 115200 baud). Software writes to LEDS drive the `LEDS` port. Bench `tb/io_tb.v`: a program that writes `5'b10101` to LEDS (checked on the `SOC` port) and sends "OK\n" over the UART, waiting on the busy bit; the bench contains a serial *receiver* model that samples `TXD` at 115200 baud (104.17 clocks per bit at 12 MHz, sample mid-bit) and checks the three received bytes.

- [ ] **Hardware demo program.** `Memory`'s initial program: print "Loop RISC-V\n" once over the UART, then cycle a pattern on LEDS forever with a software delay loop; delay constant small under `` `ifdef BENCH `` (so `tb/soc_tb.v` can check the banner and the first three LED patterns in simulation) and ~0.25 s per step on hardware. After this task the human runs `make prog` and `make uart`.
